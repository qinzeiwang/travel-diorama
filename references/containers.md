# 容器规则

只读取本次使用的容器项。用户指定优先，未指定使用透明玻璃瓶；通过尺寸和纵深调整容纳原场景。

| 容器 | 构图规则 | 硬性检查 |
| --- | --- | --- |
| 玻璃瓶 / 广口瓶 | 优先较宽、透明、可辨瓶口与瓶底的瓶形。地形落底，露出薄底座的前缘或侧缘；树木与建筑形成独立体积，侧面或上方与玻璃留可见空隙，远端收束在有限模型内。 | 不是“照片套玻璃框”；主景不被强反光遮住；道路和树木不穿壁、不穿塞；瓶内空间不是无限延伸的真实街道。 |
| 打开的行李箱 | 下半部承载前景与中景，上半部承接远景及立体浅浮雕，浮雕边缘厚度或层间阴影可见。两半有连续内容，但不平均塞满。保留箱沿、铰链、提手和支撑逻辑。 | 不能只有箱底有景；上盖不能完全是一张平面照片。立体浅浮雕可与天空背衬结合；不可让路面无缘无故沿盖子垂直爬升。 |
| 鱼缸 / 玻璃展示缸 | 按横向景观展开。薄地形底座支承在缸底，前缘或侧缘可见，与玻璃留空隙；山体有侧面和顶缘，上方留空；道路、树林、建筑可以做干景。 | 不因“鱼缸”自动灌水、加鱼、气泡和珊瑚；陆景不变海底。 |
| 其他容器 | 按开口、容量和支承方式调整取景，保留照片的识别锚点。 | 不擅自换掉用户指定容器，不破坏照片的核心关系。 |

保留云雾对原景物的遮挡与低对比关系，可用柔和氛围或低干扰背衬表达；不添加悬浮棉团式云朵，不让实体山体借天空贴片无限延伸。

外部默认简洁台面、低干扰背景和接触阴影，不加地图、护照、旅游标贴、贝壳或纪念文字。外部场景不再重建另一套旅游风光。

脚本仅支持 bottle、suitcase、tank。使用其他容器时直接依据规则组织提示词，无需运行脚本。
